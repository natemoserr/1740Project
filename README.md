# 1740 Project – Title V Permit Backlog Analysis

## Overview
This project focuses on analyzing Title V permit data to understand backlog trends across regions and facilities. The goal is to identify how long permits take to process and highlight delays using data visualizations and a dashboard.

---

## Project Structure

### Analysis Notebooks
Jupyter Notebooks used to clean, filter, and analyze the dataset.  
These notebooks generate the visualizations used to understand backlog trends, including:
- Processing time calculations  
- Backlog identification (18-month threshold)  
- Regional and yearly comparisons  

---

### Data
Contains the datasets used throughout the project:
- CSV files with filtered permit data  
- JSON files used to power the dashboard visuals  

---

### Python Apps
Backend Python scripts that process data and support the dashboard.  
These scripts handle:
- Data preparation  
- Formatting outputs for visualization  

---

### Dashboard HTML
HTML file that displays the final dashboard.  
This includes visual representations of:
- Backlog trends over time  
- Regional comparisons  
- Interactive or structured data views  

---

## Tools & Technologies
- Python  
- pandas  
- matplotlib  
- plotly  
- Jupyter Notebook  
- HTML  

---

## Key Features
- Calculates processing time for permits  
- Identifies backlogged permits (over 18 months / 548 days)  
- Visualizes trends across years and regions  
- Dashboard for displaying results
